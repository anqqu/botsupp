# Support Bot

Telegram-бот поддержки с тикет-системой на aiogram 3 + PostgreSQL.

## Возможности

- Тикет-система: каждый пользователь — отдельный топик в группе поддержки
- Reply из топика → сообщение пользователю
- Свободные сообщения в топике → внутреннее обсуждение
- /delete — удалить отправленное пользователю сообщение
- /close — закрыть тикет
- Система банов с апелляциями
- Агенты поддержки

## Быстрый старт

### 1. Клонировать репо

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
```

### 2. Создать .env из шаблона

```bash
cp .env.example .env
nano .env   # Вписать токен, ID группы и пароль БД
```

### 3. Запустить

```bash
docker compose up -d --build
```

### 4. Посмотреть логи

```bash
docker compose logs -f bot
```

### Остановить

```bash
docker compose down
```

### Остановить и удалить базу данных

```bash
docker compose down -v
```

## Команды группы поддержки

| Команда | Описание |
|---|---|
| /close | Закрыть тикет (в топике) |
| /delete | Удалить сообщение у пользователя (reply) |
| /ban <причина> | Заблокировать пользователя (reply) |
| /unban | Разблокировать (reply или user_id) |
| /banlist | Список заблокированных |
| /banhistory | История блокировок |
| /addagent | Добавить агента |
| /removeagent | Удалить агента |
| /listagents | Список агентов |
| /export | Экспорт тикетов в JSON |

## Команды пользователя

| Команда | Описание |
|---|---|
| /start | Начать общение |
| /appeal | Подать апелляцию (только для забаненных) |
| /help | Помощь |
